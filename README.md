# 🎮 Buy-Games

Site estático de loja de jogos desenvolvido com **HTML5** e **CSS3**, simulando o fluxo completo de compra: login, cadastro, catálogo de jogos, pagamento e confirmação.

🔗 **Demo:** https://gabrieltardin.github.io/Buy-Games/

## 📋 Sobre o projeto

Este projeto foi desenvolvido como prática de front-end, reproduzindo a jornada de um usuário em uma loja de jogos online, desde o acesso até a finalização da compra.

## 🖥️ Páginas

| Etapa | Descrição |
|---|---|
| `1. Login` | Tela de autenticação do usuário |
| `2. Cadastro` | Formulário de criação de conta |
| `3. Área_Jogos` | Catálogo/vitrine de jogos disponíveis |
| `4. Pagamento` | Tela de finalização de compra |
| `5. Confirmação` | Confirmação do pedido |

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 🚀 Como visualizar o projeto

```bash
# Clone o repositório
git clone https://github.com/gabrieltardin/Buy-Games.git

# Entre na pasta
cd Buy-Games

# Abra o index.html no navegador
```

Ou acesse diretamente pela versão publicada no GitHub Pages: https://gabrieltardin.github.io/Buy-Games/
